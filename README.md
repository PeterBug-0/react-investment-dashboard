# React Investment Dashboard

A clean and intuitive React-based dashboard application designed to track, analyze, and visualize your investment data. This project simplifies the process of managing your investments by providing real-time updates, analytics, and insightful visualizations.

## Features

- Real-time tracking of investment portfolio performance.
- Interactive graphs and charts to visualize trends and analytics.
- User-friendly interface for easy navigation and management.
- Responsive design compatible with desktop and mobile devices.

## Tech Stack

- **React** (Frontend library)
- **Vite** (Build tool)
- **Tailwind CSS** (Utility-first CSS framework)
- **Recharts** (Charting library)
- **Cypress** (End-to-end testing)
